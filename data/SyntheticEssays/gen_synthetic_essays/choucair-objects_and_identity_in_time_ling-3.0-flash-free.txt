The persistence of material objects through time is one of the most enduring puzzles in metaphysics. We observe a pencil named Penny on a desk in the morning; by the afternoon, she has been sharpened, leaving behind a pile of wood shavings and a shorter, narrower form. Intuitively, we believe that Penny at the morning is the very same object as Penny at the afternoon. Yet, the morning Penny and the afternoon Penny differ materially; they occupy different spatial regions and possess entirely distinct physical properties. How can a single material object undergo such profound physical transformation while remaining numerically identical to itself?

One proposed ontological framework seeks to resolve this tension by denying that material objects possess temporal parts or continuous spatiotemporal extensions. Instead, this framework claims that material objects exist only for single instants. A macroscopic object such as Penny is understood not as a continuous entity, but as an ordered sequence of instantaneous physical entities designated as object*s. In this view, the morning Penny is object*s1, the afternoon sharpened Penny is object*s2, and the identity of Penny through time is nothing over and above the abstract sequence comprising these distinct instantaneous entities. While this instantaneous state theory offers an elegant mechanism for accounting for physical change, it faces a profound philosophical objection: by defining material objects as temporal sequences of distinct momentary states, it violates the principle that an object must be necessarily self-identical across time. To evaluate this claim rigorously, we must utilize Saul Kripke’s distinction between rigid and nonrigid designation, which illuminates the modal and identity-theoretic failures inherent in the instantaneous state sequence framework.

Saul Kripke’s seminal work on naming and necessity introduced a crucial distinction between rigid and nonrigid designators that fundamentally reshaped modal logic and the metaphysics of identity. A rigid designator is a term that refers to the same object in every possible world in which that object exists. For example, the name ‘Richard Nixon’ rigidly designates the thirty-seventh President of the United States; in any possible world where Nixon exists, the term ‘Richard Nixon’ picks out that very same individual. Conversely, a nonrigid designator is a term that can refer to different objects in different possible worlds. The description ‘the President of the United States in 1970’ is nonrigid; in the actual world, it refers to Nixon, but in a possible world where Humphrey had won the 1968 election, the same description refers to Hubert Humphrey. The critical metaphysical implication of this distinction, as Kripke argues, is that if a proper name is a rigid designator, then the object it designates possesses its identity and essential properties necessarily. If Nixon is rigidly designated, it is not merely contingent that Nixon was the President in 1970; rather, Nixon is essentially the President in 1970, because the name itself fixes the referent across all possible worlds.

When we turn to the instantaneous state sequence framework, we must ask: how does the name ‘Penny’ function as a designator? According to the framework, the macroscopic object Penny is an ordered sequence of instantaneous physical entities, denoted as object*s, where object*s1 is the state at t1, object*s2 is the state at t2, and so forth. The identity of Penny through time is constituted entirely by the abstract ordering relation that holds among these distinct instantaneous entities. If we apply Kripke’s distinction, we must determine whether ‘Penny’ rigidly designates the object, or nonrigidly designates a series of distinct instantaneous states. 

If ‘Penny’ rigidly designates the object, then ‘Penny’ must refer to the very same entity in every possible world and at every temporal stage. However, the instantaneous state framework explicitly denies that the object at t1 (object*s1) is numerically identical to the object at t2 (object*s2). Object*s1 and object*s2 are distinct instantaneous physical entities; they possess different shapes, different spatial coordinates, and different microphysical configurations. If the object at t1 is object*s1 and the object at t2 is object*s2, and object*s1 is not identical to object*s2, then the entity designated by ‘Penny’ at t1 is distinct from the entity designated by ‘Penny’ at t2. Consequently, ‘Penny’ functions as a nonrigid designator. It designates object*s1 at t1, object*s2 at t2, and a different instantaneous entity at every subsequent moment. 

This nonrigidity is not merely a semantic quirk; it has devastating consequences for the ontological framework. If ‘Penny’ is a nonrigid designator, then the claim that ‘Penny’ refers to a single, unified material object that persists through time is false. Instead, ‘Penny’ is a sortal term that picks out a series of distinct, numerically different instantaneous objects. The sequence of object*s is an abstract logical or mathematical order imposed upon a collection of disparate entities, rather than the name of a single enduring entity. The framework thus reduces the material object to a mereological sum or a mere series, losing the necessary self-identity that characterizes a genuine persisting object.

The central tension of the instantaneous state framework lies in its attempt to account for physical change—such as the sharpening of a pencil—while retaining a consistent identity. The framework posits that change is not the alteration of a persisting object, but rather the replacement of one instantaneous state with another. When Penny is sharpened, object*s1 (the unsharpened state) ceases to exist, and object*s2 (the sharpened state) comes into being. The relationship between object*s1 and object*s2 is not one of alteration, but of succession within an ordered sequence. The identity of Penny is preserved not through the continuity of a single entity, but through the abstract relation that binds the sequence together. 

On the surface, this accounts for change elegantly. We do not have to posit a mysterious capacity for an object to alter its intrinsic properties while remaining numerically the same. Instead, the intrinsic properties change because the instantaneous entity itself changes. The sequence merely records these transitions. However, this elegance comes at the cost of explanatory depth. The framework provides an account of the *formal* structure of change—the fact that states succeed one another—but it fails to provide an ontological account of *why* these states are unified as a single object rather than merely a coincidental collection of unrelated momentary entities. 

Consider the instantaneous entities object*s1 and object*s2. They are physically contiguous in time, and they share a causal history; object*s1 is the direct causal precursor to object*s2. Yet, contiguity and causal dependence are relations, not entities. The sequence <object*s1, object*s2, object*s3...> is an abstract set-theoretic or topological structure. The framework claims that the material object *is* this abstract sequence. But an abstract sequence is not a material object. A material object possesses mass, charge, and spatial extension. An abstract sequence possesses logical order and cardinality. By identifying the material object with the abstract sequence, the framework commits a category mistake, conflating the ontological substrate (the instantaneous physical entities) with the structural relation that orders them (the sequence). The instantaneous entities exist only for single instants; the sequence exists as a timeless, abstract whole. The material object cannot be the abstract whole, for the abstract whole is not material. Nor can the material object be the instantaneous entities, for they are numerically distinct across time. Thus, the framework leaves the ontological status of the material object suspended between a series of distinct physical states and an abstract logical construct.

This brings us to the central objection: defining material objects as temporal sequences of distinct momentary states violates the principle that an object must be necessarily self-identical across time. The principle of necessary self-identity states that if an object x exists at time t1 and exists at time t2, then x at t1 is strictly identical to x at t2. This identity is not contingent or derivative; it is a necessary truth grounded in the law of identity (x = x). For a material object, this necessary self-identity implies that the object possesses an essential identity that transcends its accidental, temporal properties. 

The instantaneous state sequence framework explicitly denies this necessary self-identity. Because the object at t1 is object*s1 and the object at t2 is object*s2, and object*s1 and object*s2 are distinct instantaneous entities, the framework entails that the object at t1 is not strictly identical to the object at t2. The identity of the object is contingent upon which instantaneous state occupies the relevant temporal slot. In world W1, the sequence begins with an unsharpened object*s1; in world W2, the sequence begins with a sharpened object*s1. Because the instantaneous states differ across possible worlds, the sequences differ, and therefore the objects designated by ‘Penny’ differ. Under Kripke’s modal framework, this means ‘Penny’ is a nonrigid designator. It does not rigidly designate a single essential object; rather, it nonrigidly designates whatever instantaneous state happens to occupy the relevant temporal position in the sequence. 

The violation of necessary self-identity becomes glaringly apparent when we consider the modal profile of the object. If the instantaneous state framework is correct, then it is not necessary that the object at t1 is the same as the object at t2. It is merely contingent that the sequence continues, and contingent that the specific instantaneous entities succeed one another in a particular order. However, for a material object like a pencil, we intuitively hold that its identity through time is necessary. If Penny is a material object, then it is necessarily the case that if Penny exists at t2, it is the very same object that existed at t1. The instantaneous state framework collapses this necessity into mere contingency. The object’s identity through time becomes a matter of abstract sequence continuation, a logical or mathematical fact about the ordering of distinct entities, rather than a metaphysical fact about the self-identity of a single material thing. 

Proponents of the instantaneous state framework might attempt to rescue necessary self-identity by arguing that the sequence *as a whole* is the object, and that the sequence is rigidly designated. On this view, ‘Penny’ rigidly designates the entire four-dimensional spacetime worm—the ordered set of all its instantaneous states. In this reading, object*s1 is not the object at t1; rather, object*s1 is a temporal part of the object. The object itself is the complete sequence. However, this move fails to satisfy the ontological constraints of the framework as originally stipulated. The framework explicitly claims that "material objects exist only for single instants." If the material object is the complete sequence, then the material object does not exist only for single instants; it exists across multiple instants. The framework collapses into a form of perdurantism or four-dimensionalism, which posits that objects are spacetime worms that possess temporal parts. But the instantaneous state sequence theory is explicitly an endurantist theory of instantaneous states, or at least a theory that denies that the object has temporal parts in the traditional perdurantist sense. It claims the object *is* the instantaneous state, not that the instantaneous state is a part of a larger temporally extended object. 

If we insist that the object *is* the instantaneous state (object*s), then the object cannot be the sequence. The sequence is a collection of objects, not a single object. To identify the single object with the collection is to commit the fallacy of division in reverse—treating a mereological sum as a single entity. The principle of necessary self-identity requires that the object at t1 is numerically identical to the object at t2. If the object at t1 is object*s1 and the object at t2 is object*s2, then for the principle to hold, object*s1 must be numerically identical to object*s2. But by the framework’s own definition, object*s1 and object*s2 are distinct instantaneous physical entities. They cannot be identical without ceasing to be distinct instantaneous entities. Therefore, the instantaneous state framework is internally inconsistent with the principle of necessary self-identity. It posits that objects exist only for single instants, yet demands that we treat the sequence of these distinct instants as a single self-identical object. The demand for necessary self-identity is thus the fatal flaw that the framework cannot circumvent.
